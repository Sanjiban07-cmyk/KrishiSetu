# 🌾 KrishiSetu

### Smart Procurement Assistance for Farmers

KrishiSetu is a web-based smart procurement assistance platform designed to help farmers find authorised procurement centres, check available slots, book procurement appointments, track procurement progress, and monitor payment status.

The system also provides an administrative portal for managing farmers, procurement centres, bookings, procurement status, and payments.

---

## 🎯 Problem Statement

**SIH26032 — Smart Procurement Assistance for Farmers**

Farmers often face:

- Long waiting times at procurement centres
- Lack of information about procurement schedules
- Difficulty finding suitable procurement centres
- Uncertainty about procurement status
- Lack of visibility into payment status

KrishiSetu aims to make the existing procurement process more transparent, organised, and easier to access.

---

## 💡 Our Solution

KrishiSetu provides a single platform where farmers can:

1. Find authorised procurement centres
2. View available procurement slots
3. Book a suitable time slot
4. Receive a unique booking token
5. Track procurement progress
6. Check payment status
7. View their latest procurement activity

Administrators can manage the operational side of the system through a dedicated Admin Portal.
